품번메모 개인정보처리방침

품번메모는 NextLine이 개발합니다.
문의: contact@nextline.work · https://nextline.work

라이브러리와 설정
저장한 작품, 폴더, 태그, 작가, 메모, 검색어, 서버 주소와 설정은 기기에 보관합니다. 두 모드는 별도 저장소를 사용합니다. NextLine 계정, 광고 SDK, 분석 SDK 또는 개발자가 운영하는 라이브러리 서버는 없습니다. 일반적인 앱 사용으로 라이브러리가 NextLine에 전달되지 않습니다.

이용하는 웹사이트
앱은 선택한 사이트와 미디어 서버에 직접 콘텐츠를 요청합니다. 해당 서비스에는 IP 주소, 요청 주소와 검색어, 요청에 필요한 인증 정보나 쿠키가 전달됩니다. 내장 브라우저에서는 사이트가 관리하는 추가 리소스가 로드될 수 있습니다. 각 운영자의 개인정보처리방침과 보관 기준이 적용되므로 신뢰하는 서비스만 연결하세요. NextLine은 해당 사이트가 보유한 기록을 관리하거나 삭제를 보장하지 않습니다.

계정 정보와 브라우저 데이터
서버 계정 정보는 기기의 키체인에 저장하며 해당 서버 접속에 사용합니다. 클라이언트 확인과 내장 브라우저의 쿠키·웹사이트 데이터는 기기에 저장됩니다. 서버 설정에서 쿠키를 지우거나 계정 입력란을 비워 인증 정보를 제거할 수 있습니다. 서버를 제거하면 해당 서버의 로컬 라이브러리, 계정 정보와 브라우저 데이터가 삭제됩니다. 키체인 정보는 앱 삭제 후에도 남을 수 있으므로 삭제하려면 앱을 지우기 전에 서버 계정 정보를 제거하세요.

iCloud
iCloud Drive를 사용할 수 있으면 동기화가 기본으로 켜집니다. 라이브러리 기록과 일부 설정은 사용자의 Apple 계정 iCloud Drive에 저장되어 기기 사이에서 병합됩니다. 미디어 파일, API 키, 브라우저 쿠키는 라이브러리 동기화에 포함되지 않습니다. 설치·기기 정보에서 만든 가명 식별자는 기기별 동기화 파일을 구별하는 데 사용하며 NextLine에 보내지 않습니다. 설정에서 동기화를 끌 수 있습니다. 이후 동기화만 중단하며 기존 기기·iCloud 데이터는 삭제하지 않습니다. 클라우드 사본을 없애려면 모든 기기에서 동기화를 끄고 Apple의 iCloud 저장 공간 관리 기능을 이용하세요. 기기 백업은 Apple 설정으로 별도 관리됩니다.

가져오기·내보내기·번역
사용자가 선택한 백업 파일에 접근하며 요청할 때만 백업을 내보냅니다. 내보낸 파일에는 개인 라이브러리 정보가 포함될 수 있으며 앱 밖에 있는 사본은 직접 삭제하기 전까지 남습니다. 이미지의 문자 인식과 번역에는 Apple 프레임워크를 사용하며 언어 리소스를 다운로드할 수 있습니다. NextLine 번역 서버로 이미지나 인식된 문자를 보내지 않습니다.

보관과 삭제
검색 기록은 기본적으로 직접 삭제할 때까지 보관합니다. 보관 기간 변경, 새 검색 기록 저장 중단, 개별 삭제와 전체 기록 삭제가 가능합니다. 저장한 검색은 별도로 보관합니다. 작품과 설정은 직접 지울 때까지 유지합니다. 폴더 삭제는 작품을 지우는 것이 아니라 소속을 해제하거나 미분류로 옮기는 동작입니다. 동기화가 켜져 있으면 지원되는 라이브러리 삭제가 다른 기기에도 병합됩니다. 이미지 미리보기는 빠른 로딩을 위해 기기에 최대 256MB까지 캐시하며 iCloud 동기화에는 포함하지 않습니다. 이미지 캐시는 원본 사이트에서 다시 만들어질 수 있으며 Booru 캐시는 설정에서 지울 수 있습니다. 앱 삭제로 로컬 컨테이너가 제거되더라도 내보낸 파일, 키체인 정보, 다른 설치 구성요소가 사용하는 공유 컨테이너와 iCloud 사본은 남을 수 있습니다.

문의와 콘텐츠 신고
이메일이나 Discord를 사용할 때 전송할 내용은 사용자가 결정합니다. 콘텐츠 신고는 원본 페이지 주소가 포함된 이메일 초안만 열며, 직접 전송해야 전달됩니다. 메일 제공자와 Discord도 해당 통신을 처리합니다. 문의 정보는 답변과 문제 조사에 사용하며 해당 목적이나 적용되는 의무에 필요한 기간만 보관합니다. 문의 정보의 삭제는 contact@nextline.work로 요청할 수 있습니다. 비밀번호나 API 키를 보내지 마세요. 외부 사이트 게시물은 해당 사이트에도 별도로 신고해야 할 수 있습니다.

방침 변경
데이터 처리 방식이 변경되면 이 방침을 갱신합니다. 최신 방침은 앱과 공개 프로젝트 저장소에서 볼 수 있습니다.

취향 분석과 온디바이스 AI
취향 분석은 기본으로 켜져 있습니다. 검색 태그 맥락, 저장·해제 활동, 비교 표본으로만 사용하는 열람 작품의 메타데이터를 기록합니다. 이미지와 만화의 취향은 분리하며 기존 보관함을 일반 취향의 초기 자료로 사용할 수 있습니다. 추천 작품을 직접 저장한 선택도 취향 근거에 반영하며, 추천 노출만으로는 선호 점수를 올리지 않습니다. 기술·관리용 태그는 취향 점수에서 제외합니다. 분석 기록과 검증한 보고서는 검색 기록 보관 기간과 별도로 직접 삭제할 때까지 보관합니다. 검색 기록 저장이 꺼져 있으면 별도 검색 이벤트는 기록하지 않지만, 저장 순간의 맥락은 취향 근거 분류에 사용할 수 있습니다.

AI는 사용 가능한 기기에서 Apple의 온디바이스 Foundation Models를 사용합니다. 모델에는 임시 익명 식별자와 미리 계산한 통계만 전달하며, 태그명·제목·이미지·사이트 주소·식별자 대응표는 전달하지 않습니다. 미지원 기기나 생성 실패 시 통계 기반 설명을 제공합니다. 개발자가 운영하는 AI 서비스로 분석 자료를 보내지 않습니다. 추천 검색에 사용하는 태그는 연결된 콘텐츠 사이트에 전달되며 해당 사이트의 정책이 적용됩니다.

라이브러리 동기화와 분석 동기화가 모두 켜져 있으면 분석 데이터를 기존 보호 수준의 iCloud Drive 별도 영역에 저장합니다. iCloud Drive의 종단간 암호화는 Apple 고급 데이터 보호 설정에 따릅니다. 설정에서 취향 분석이나 AI 해설을 중지할 수 있습니다. 분석 중지 설정은 다른 기기의 다음 동기화 때 적용되며 오프라인 기기에 즉시 전달되지는 않습니다. 분석 기록 삭제는 보관함을 유지하면서 앱이 관리하는 분석 기록과 보고서를 동기화되는 기기에서 삭제하고 과거 기록의 재병합을 차단합니다. iCloud에 접근할 수 없으면 삭제가 대기할 수 있습니다. 삭제 후 기존 저장 작품을 자동으로 재분석하지 않습니다. 앱 밖의 사본과 Apple의 백업·버전 기록은 별도로 관리됩니다.
